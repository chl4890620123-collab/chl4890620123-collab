# 최명헌 | 정보기술 개발 · 백엔드·AI 서비스

현장 업무와 물류·재고 관리 경험에서 발견한 불편을 소프트웨어로 해결하고 싶어 개발을 시작했습니다.  
Java·Spring Boot, React, Python·FastAPI를 활용해 웹 서비스와 AI 기능을 만들고, 데이터·권한·배포까지 이어지는 구조를 프로젝트에서 다루고 있습니다.

AI 도구를 개발 보조로 활용하되, 생성된 코드의 동작과 보안 설정을 직접 확인하는 것을 중요하게 생각합니다. 사용자가 실제로 편리하게 쓸 수 있는 기능을 만들고, 운영 단계에서도 이해하고 관리할 수 있는 서비스를 지향합니다.

- **지원 분야:** 정보기술 개발 · 백엔드 개발 · AI 서비스 개발
- **주요 기술:** Java, Spring Boot, Python, FastAPI, SQL, React, Vue.js, Docker, Git
- **관심 분야:** 물류·재고 서비스, 업무 자동화, 사용자 중심 AI, 배포·운영

---

## 대표 프로젝트

### [Restok — 물품 생애주기 관리](https://github.com/chl4890620123-collab/Restok-Rangchain)

물품을 등록한 뒤 사용·판매·기부·재활용·폐기까지 관리하는 URL 중심 플랫폼입니다. 물류·재고 업무에서 본 낭비와 불편을 개발 주제로 연결했습니다.

- 입고·출고와 상품 정보를 기록하고, 사용자가 기본값을 수정해 상세 정보를 관리
- 시간 기준 처리와 자동 정리 기능을 포함한 반자동 관리 흐름
- 사용자가 거래처·판매처 등의 URL을 직접 등록해 다양한 처리 경로를 선택
- 대시보드와 상세 화면으로 현재 물품과 처리 이력을 확인
- 영수증 분석과 보유 데이터 기반 AI 보조 기능을 서비스에 연결

**기술:** Java · Spring Boot · React · FastAPI · Gemini · MariaDB · Docker

### [Hub — 사내 업무 AI 허브](https://github.com/chl4890620123-collab/hub)

문서·회의 자료를 검색하는 데서 끝나지 않고, 근거 확인부터 담당자 업무와 관리자 검토까지 연결하는 플랫폼입니다.

- 검색 답변을 원문 근거와 연결해 사용자가 확인할 수 있도록 구성
- AI 후보 검토, 담당자 지정, 결과 제출, 관리자 승인으로 이어지는 업무 흐름
- Spring Boot 백엔드, React·TypeScript 화면, FastAPI AI 서비스 분리
- Docker와 GitHub Actions를 활용한 검증·배포 구조

**기술:** Java · Spring Boot · React · TypeScript · Python · FastAPI · PostgreSQL · Docker · GitHub Actions

### [AITM — AI 태권도 동작 분석](https://github.com/chl4890620123-collab/Aitm)

영상에서 포즈와 관절 좌표를 분석해 태권도 동작을 측정하고 코칭 정보를 제공하는 서비스입니다.

- MediaPipe와 OpenCV 기반 동작·관절 분석
- 무릎 각도, 회전, 타이밍, 착지 등의 측정값을 기준으로 점수 산출
- 분석 신뢰도에 따라 결과 확정과 검토 필요 상태를 구분
- 포즈 오버레이와 문제 시점 느린 재생으로 결과 근거 확인

**기술:** Java · Spring Boot · React · Python · FastAPI · MediaPipe · OpenCV · MariaDB · Docker

### [Maple Craft Analytics — 제작·판매 분석](https://github.com/chl4890620123-collab/maple)

메이플스토리 제작품의 재료비, 판매가, 수수료와 실제 판매 이력을 관리해 수익을 분석하는 프로젝트입니다.

- 레시피 기반 제작비와 예상 수익 계산
- 재료·판매 가격 변경 이력과 실제 제작·판매 기록 관리
- 예상 수익과 실현 수익을 비교해 추천을 점진적으로 보정
- SQLite 회귀 테스트, MariaDB 통합 테스트, Docker 빌드 CI 구성

**기술:** Python · FastAPI · MariaDB · SQLite · Docker · GitHub Actions

### [Server — 중앙 운영 인프라](https://github.com/chl4890620123-collab/Server)

여러 앱의 운영 환경과 배포 구성을 관리하는 인프라 저장소입니다.

- 앱 코드와 운영 설정의 책임 분리
- Docker Compose, Caddy, 배포·검증 스크립트 관리
- 운영 데이터와 비밀 설정을 소스 코드에서 분리

**기술:** Docker Compose · Caddy · GitHub Actions · PowerShell

## 개발자로서의 방향

현장 경험을 바탕으로 사용자가 반복해서 겪는 불편을 찾고, 이를 이해하기 쉬운 서비스 흐름으로 바꾸는 데 관심이 있습니다. Restok에서는 물품 관리 경험을 입고·출고, 사용자 지정 URL, 이력 관리와 AI 보조 기능으로 구체화했습니다.

협업에서는 회의 내용을 정리해 공유하고, 주석과 문서로 코드의 의도와 동작을 설명하는 방식을 중요하게 생각합니다. AI가 생성한 코드도 그대로 적용하지 않고, 로직·중복·보안 설정을 확인하며 안정적인 구조로 다듬는 개발자가 되겠습니다.
