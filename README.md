# 최명헌 | 백엔드·AI 서비스 개발

현장 업무 경험과 실무형 개발 교육을 바탕으로, 사용자의 문제를 웹 서비스로 구현하는 개발자로 성장하고 있습니다.  
Java·Spring Boot와 Python·FastAPI를 중심으로 웹 애플리케이션, AI 기능, 데이터 처리와 배포 흐름을 프로젝트에서 다루고 있습니다.

- **관심 직무:** 백엔드 개발 · AI 서비스 개발 · 웹 애플리케이션 개발
- **주요 기술:** Java, Spring Boot, Python, FastAPI, SQL, React, TypeScript, Docker, Git
- **포트폴리오:** 대표 프로젝트와 저장소는 아래에서 확인할 수 있습니다.

---

## 대표 프로젝트

### [Hub — 사내 업무 AI 허브](https://github.com/chl4890620123-collab/hub)

문서와 회의 자료 검색을 실제 업무 배정과 결과 검토까지 연결하는 업무 플랫폼입니다.

- 자료 검색 결과를 원문 근거와 연결하고, 사용자가 확인할 수 있는 흐름을 구성
- AI 후보 검토, 담당자 지정, 결과 제출, 관리자 승인으로 이어지는 역할 기반 업무 흐름
- Spring Boot 백엔드, React·TypeScript 웹 화면, FastAPI AI 서비스를 분리한 구조
- Docker와 GitHub Actions를 활용한 검증·배포 구성

**기술:** Java · Spring Boot · React · TypeScript · Python · FastAPI · PostgreSQL · Docker · GitHub Actions

### [AITM — AI 태권도 동작 분석](https://github.com/chl4890620123-collab/Aitm)

영상에서 포즈와 관절 좌표를 분석하고, 측정값을 바탕으로 코칭 정보를 제공하는 서비스입니다.

- MediaPipe와 OpenCV를 활용한 동작·관절 분석
- 무릎 각도, 회전, 타이밍, 착지 등을 기준으로 점수 산출
- 분석 신뢰도에 따라 결과 확정과 검토 필요 상태를 구분
- 포즈 오버레이와 문제 시점 느린 재생으로 결과 근거 확인

**기술:** Java · Spring Boot · React · Python · FastAPI · MediaPipe · OpenCV · MariaDB · Docker

### [Restok — 물품 생애주기 관리](https://github.com/chl4890620123-collab/Restok-Rangchain)

물품의 등록부터 사용, 판매, 기부, 재활용, 폐기까지 이력을 기록하는 플랫폼입니다.

- 사용자가 등록한 URL을 통해 다양한 외부 처리 경로를 연결
- 영수증 분석과 보유·처리 이력을 활용한 AI 보조 기능
- React, Spring Boot, FastAPI 서비스를 Docker 환경에서 연동
- 사용자별 물품 접근과 운영 데이터 분리를 고려한 구조

**기술:** Java · Spring Boot · React · FastAPI · Gemini · MariaDB · Docker

### [Maple Craft Analytics — 제작·판매 분석](https://github.com/chl4890620123-collab/maple)

메이플스토리 제작품의 재료비와 판매 기록을 관리하고 실제 수익을 분석하는 프로젝트입니다.

- 재료·판매 가격과 변경 이력 관리
- 레시피 기반 제작비, 수수료, 예상 수익 계산
- 실제 제작·판매 기록을 사용해 예상 수익과 실현 수익 비교
- SQLite 회귀 테스트, MariaDB 통합 테스트, Docker 이미지 빌드 CI 구성

**기술:** Python · FastAPI · MariaDB · SQLite · Docker · GitHub Actions

### [Server — 중앙 운영 인프라](https://github.com/chl4890620123-collab/Server)

여러 앱의 운영 환경과 배포 구성을 관리하는 인프라 저장소입니다.

- 애플리케이션 코드와 운영 환경 설정 분리
- Docker Compose, Caddy, 배포·검증 스크립트 관리
- 운영 데이터와 비밀 설정을 소스 코드에서 분리
- 배포 전후 상태를 확인할 수 있는 검증 흐름 구성

**기술:** Docker Compose · Caddy · GitHub Actions · PowerShell
